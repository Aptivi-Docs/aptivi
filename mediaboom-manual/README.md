# Welcome!

<figure><img src=".gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>

MediaBoom is a music and video player made with C# using the libmpv library as the native backend that handles playback and song information.

This library is a viable library aimed for cross-platform music and video playing because we've selected libmpv as the backend library for its ease of use and for its fast playback. This library is frictionless as it aims for stability and cross-platform compatibility.

In addition to your regular music files, MediaBoom also supports online radio stations that you can use to play your own favorite radio stations.

To learn more about libmpv, visit this site:
