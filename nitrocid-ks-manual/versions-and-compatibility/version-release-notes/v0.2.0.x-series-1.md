# v0.2.1.x series

<figure><img src="../../.gitbook/assets/image (343).png" alt=""><figcaption></figcaption></figure>

This kernel version series is built on top of API v4.0, which brings many major changes to the API. The new API version ensures that your kernel and its addons and mods becomes more powerful than before, with the needed API refactors, deprecations, removals, and improvements.

{% hint style="info" %}
You can check out more detailed changelogs using the `changes` command. Quick overview of the changes can be found in the [Releases](https://github.com/Aptivi/NitrocidKS/releases) page.
{% endhint %}

***

## <mark style="color:$primary;">Version 0.2.1.x series</mark>

This series started with API version v4.1.29.65 for the final version of Nitrocid KS 0.2.1, which was released on November 5th, 2026. The pre-release versions of Nitrocid 0.2.1 were:

* Tech Preview - API v4.1.29.6 - June 27th, 2026
* Release Candidate - API v4.1.29.59 - October 8th, 2026

Here's a list of versions that were released:

<details>

<summary>Version 0.2.1.0</summary>

The following changes were made:

* <mark style="color:green;">Added user and group management TUI</mark>
* <mark style="color:green;">Restored POP mail</mark>
* <mark style="color:green;">Added search function for config and The Nitrocid Homepage</mark>
* <mark style="color:green;">Added UNIX permission function</mark>
* <mark style="color:green;">Added new screensavers and splashes</mark>
* <mark style="color:green;">Added official support for FreeBSD</mark>
* <mark style="color:yellow;">Improved calendar rendering</mark>
* <mark style="color:yellow;">Improved the kernel codebase</mark>
* <mark style="color:yellow;">Made the Windows installer more modular</mark>
* <mark style="color:yellow;">Improved how splashes open and close</mark>
* <mark style="color:yellow;">Performance improvements</mark>
* <mark style="color:yellow;">General improvements and bug fixes</mark>
* <mark style="color:red;">Removed kernel tips</mark>
* <mark style="color:red;">Removed legacy theme studio</mark>

</details>
