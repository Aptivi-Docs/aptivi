# Welcome

Colorimetry is a library that allows you to centrally manage colors in various types, from 16 console colors to 256 console colors, with true color support in various formats. It does not only provide RGB, CMYK, and CMY support, but it also provides tools related to transformation and other common and uncommon color manipulation tools.
